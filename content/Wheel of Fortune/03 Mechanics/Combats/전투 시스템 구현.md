# 전투 시스템 정리

> Unity 6.3 LTS / 2D URP / New Input System (Send Messages + 일부 폴링) 프로젝트: 운명의 수레바퀴(가제)

## 1. 파일 구성

|파일|역할|

### 플레이어 컴포넌트

`Rigidbody2D + CapsuleCollider2D + PlayerInput + PlayerMovement + PlayerAttack + FragmentLoadout + PlayerDodge + PlayerParry + PatternResponder + Health(None) + Stamina + StatusEffects + KnockbackReceiver`

### 입력 액션 (InputSystem_Actions / Player 맵)

|액션|키|방식|
|---|---|---|
|Attack|좌클릭|폴링 (홀드 판별)|
|Swap|Q|Send Messages|
|SpecialAttack|E|Send Messages|
|Dodge|Left Shift|Send Messages|
|Parry|우클릭|Send Messages + 폴링|

**주의**: 액션 이름 오타 시 조용히 무시. 뗌 이벤트는 신뢰 불가 → 홀드 판별은 `IsPressed()` 폴링.

## 2. 데이터 구조: 무기 × 파편

- **WeaponData**: 무기군(둔기/검/채찍/주먹/창) + 무게(경량/표준/중량) + damage/weightDamage/range + `defaultFragment`(공통 모션, **비면 공격 불가**)
- **MemoryFragmentData**: 계열/무게, 단계 1~4, 고유효과(메인/서브 모두 적용), combo/heavyAttack/specialSkill/swapAttack
- **AttackStep**: startup/recovery/cancelable/hyperArmor, 배율 3종, hitbox+offset, staminaCost, knockback
- 장착: 무기군 무관 (주먹만 같은 계열 강제 - 현재 경고만)

### 공격 결정 (파편 단계)

|공격|조건|데이터|
|---|---|---|
|기본 콤보|3단계+ / 미만|파편 combo / 무기 defaultFragment.combo|
|강공격|2단계+ / 1단계|파편 heavyAttack / defaultFragment.heavyAttack|
|특수 스킬 (E)|4단계만|specialSkill|
|스왑 스킬 (Q)|제한 없음|swapAttack|

## 3. 입력/캔슬 규칙

- 기본공격 = 짧게 눌렀다 뗌 / 강공격 = 0.25s+ 홀드 후 뗌
- 버퍼: 공격 종료 0.16s 전부터만 접수, 기본공격만. 강공격 선충전 금지
- 콤보 반복 순환, 후딜 후 0.4s 내 입력 없으면 1타로
- **캔슬**: cancelable 스텝의 후딜 중에만 스왑/특수/회피/패링 끼어들기 가능. 선딜~히트는 불가
- **히트스턴**: 넉백>0 공격 피격 시 시전 중 공격 강제 캔슬 (히트 전이면 데미지도 무산)
- **하이퍼아머**: 스텝 hyperArmor 또는 HyperArmorState → 히트스턴/넉백 무시
- 스왑: 서브 있으면 교체+새 메인의 스왑 스킬 / 메인만이면 자기 스왑 스킬. 쿨 8s

## 4. 데미지 파이프라인

```
최종 = 무기.damage × step.damageMult (=baseDamage) × 공격자 DamageDealt × 대상 DamageTaken
```

로그: `피격! 21 = 기본 15 x 버프 1.4 x 디버프 1, 남은 HP 79`

### StatusEffects — value는 배수

- 1 = 변화 없음, 1.5 = 1.5배, 0.7 = 0.7배. 합연산: 1.5배+1.2배 = 1.7배
- 같은 id는 갱신. 시작 버프는 `InitialStatusEffects` 컴포넌트로
- **주의**: 스크립트 기본값 변경은 이미 저장된 인스펙터 값에 영향 없음

## 5. 히트 판정

- 타격 순간 OverlapBox 즉석 검사. AttackPoint가 안쪽 끝, 전방으로만 뻗음 + 스텝 offset
- 디버그 표시: 플레이어 빨강 / 적 주황 (`HitboxDebug.Show`, Show Hitbox 토글)
- 벽 반동: 히트박스가 wallLayer에 닿으면 반대로 밀림 (Y 유지)

## 6. 피격 / 넉백 / 사망

### Health

- `DeathBehavior`: **Destroy**(일회성 잡몹) / **Deactivate**(리스폰 대상 적) / **None**(플레이어)
- 이벤트: OnChanged / OnDamaged / **OnDamageIgnored**(무적으로 씹음 - 저스트회피 판정) / OnDeath
- `DamageInterceptor`(패링/방어), `SetInvulnerable`(회피), `Revive`(리스폰)

### KnockbackReceiver

- 공격자 반대로 밀림+경직 0.15s → 경직 중 감속 → 종료 시 정지 (연출용, 안 미끄러짐)
- 경직 중 조작 무시, 히트스턴 캔슬/하이퍼아머 판단
- 플레이어×적 물리 충돌은 Layer Collision Matrix에서 해제

### 리스폰 (RespawnManager + Checkpoint)

- 플레이어 사망 → 조작 정지 → 1.5s 후 체크포인트에서 부활 (HP/스태미나 풀)
- 씬의 모든 적 리셋: 위치/체력 복구, Deactivate로 죽은 적 부활 (Destroy는 복구 불가)
- 체크포인트 = 트리거 콜라이더 + Checkpoint 스크립트. 기본값은 시작 위치
- 적 스크립트는 OnEnable에서 공격 상태 초기화 (부활 시 얼어붙음 방지)

## 7. 회피 / 패링 / 방어

### 회피 (Shift)

- 지상 구르기(12, 0.35s) / 공중 대시(18, 0.15s, 중력 정지, 착지까지 1회)
- 전체 무적 + 조작 잠금, 스태미나 3

### 패링/방어 (우클릭)

- **짧게 = 패링**: 판정 0.15s, 방향 무관. 성공 시 무효+스태미나 환급+공격자 경직 0.6s. 헛침 0.3s 후딜
- **특수 패링**: 무게 > blockLimit 공격을 패링 → 마나/혈액 회복 (TODO)
- **홀드 = 방어**: 회복 정지, 성공 조건 = guardable + 무게 ≤ 10 + 스태미나 충분 → 무게만큼 소모
- **가드 브레이크** (방어 실패 통합: 방어 불가 공격/한계 초과/스태미나 부족): 스태미나 무게만큼 깎임(최저 3 보장) + **뚫은 그 공격만** 1.4배 + 방어 풀림

## 8. 파훼 시스템

### 데이터

- **AttackPatternData** (SO): 패턴의 모든 것 — patternId(저장 키, 중복 금지!), 대응 방법 플래그(JustDodge/Parry/SpecialParry, Jump는 미구현), 데미지/무게/넉백/guardable, startup/recovery/cooldown, triggerRange/hitbox, **구간별 이동**(startupMove/activeMove/recoveryMove, 양수=전방 음수=후방), activeDuration(0=즉발, >0=지속 판정), 전조 색
- **PatternRecordStore** (정적): `Dictionary<patternId, PatternRecord>` + JSON 영구 저장 (`persistentDataPath/pattern_records.json`). 회차/재시작에도 유지

### 규칙 (2단계 기록)

- 시전 중 피격 +1 / 시전 중 사망 +3 / fail 증가 시 success 리셋
- 완벽 대응: success +1, fail −1
- **fail ≥ 6 → 흐린 기록(Faint)**: 전조 표시만 (전조 흰색) — "몸으로 배운 기억"
- **success ≥ 2 → 선명한 기록(Clear)**: 전조(하늘색) + 대응 시 스왑 쿨 초기화 — Faint에서 승급 가능
- Clear 후 스택 동결

### 판정 흐름

- 적(IPatternUser)이 CurrentPattern을 노출 → 플레이어의 **PatternResponder**가 공격자를 역추적해 보고
    - 피격/사망: Health.OnDamaged/OnDeath
    - 패링: PlayerParry.OnParrySuccess(특수 여부 포함)
    - 저스트회피: Health.OnDamageIgnored + 회피 중이었는지
- 기록 초기화: PatternResponder 컴포넌트 우클릭 → "파훼 기록 전체 초기화"

## 9. 적 구성

### EliteEnemy (정예 - 파훼 대상)

- AttackPatternData 리스트만 꽂으면 됨. 쿨타임은 런타임 관리 (SO에 상태 저장 금지)
- 패턴 3구간: 전조(이동 가능) → 히트(즉발 or 지속+이동) → 후딜(이동 가능). 방향은 시전 시작 시 고정
- 전조 색: 기본 노랑 / 흐린 기록 흰색 / 선명한 기록 하늘색
- 구성: Health(**Deactivate**) + Rigidbody2D + KnockbackReceiver + Collider + Enemy 레이어, Player Layer 지정

### EnemyMovement (이동 AI - 정예/일반 공용)

- 순찰: patrolSpeed로 걷다가 벽/낭떠러지에서 반전 (자식 **EdgeCheck**=전방 발끝 아래, **WallCheck**=전방 벽 높이)
- 추적: detectionRange 안에 플레이어 → chaseSpeed로 접근, stopDistance에서 정지 (공격 사거리에 맞출 것)
- 공격 중(EliteEnemy)/경직 중에는 이동 안 함 — 패턴 이동과 충돌 방지
- 방향 전환 = 스케일 뒤집기 → 체크 포인트 자동 반전

### 더미

- TrainingDummy: 안 죽는 샌드백 (3s 후 회복)
- DummyAttacker: 단순 전조→공격 (guardable 토글)
