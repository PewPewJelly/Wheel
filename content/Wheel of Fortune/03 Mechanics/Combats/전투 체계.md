# 개요 
- 반응속도 기반의 세미 소울라이크 방식.
- 무기, [[기억의 파편]] 별로 다양한 빌드와 스타일을 차용 가능

## 기본적인 조작

- **기본공격**
  * 가장 기본이 되는 공격
	  * 기본공격은 반복되는 콤보 형식으로, 1타 ~ n타 까지 존재함
- **강공격**
  * 높은 *피해를 주는 공격
- **회피**
  * 상대의 공격을 피함
- **패링**
  * 상대의 공격을 받아침. 패링 성공 시 스테미나 소모가 0이됨.
- **방어**
  * 상대의 공격을 막음.
  * 공격 방어시에는 상대의 **무게 공격력** 만큼의 스테미나 피해를 입음.
  * 한 번의 방어시 사용할 수 있는 스테미나는 정해져 있음. 이를 넘어가는 공격은 방어가 불가함.
- **특수 패링**
  * 한 번의 방어 시 정해져 있는 스테미나 최대치(한계치) 를 넘는 공격을 패링하였을때 일어남. 상대의 공격에서 마나 또는 혈액을 채움.

# 데미지 계산
- 플레이어가 주는 데미지
	- 무기 데미지 * (파편의 보정치) * (데미지 버프) * (적에게 있는 디버프)
		- 데미지 버프/디버프 끼리는 합연산
	- 무게 데미지 = 무기의 무게 데미지 * (파편의 보정치) * (버프) * (디버프)
	- 사거리 계산 = 무기의 사거리 * (파편의 보정치)
- 플레이어가 받는(적의) 데미지
	- 공격의 데미지 * (플레이어가 가지고 있는 디버프) * (적이 가지고 있는 데미지 버프)
		- 버프/디버프 끼리는 합연산
	- 무게 데미지 = 공격의 무게 데미지 * (버프) * (디버프)

## 2. 데이터 구조: 무기 × 파편

### WeaponData

- `WeaponClass`(둔기/검/채찍/주먹/창) + `WeightClass`(경량/표준/중량)
- 기본 수치: `damage`, `weightDamage`, `range`(히트박스 가로 배수)
- `defaultFragment`: 무기군-무게 공통 모션용 기본 파편. **비면 공격 불가 (Awake 에러 로그)**

### MemoryFragmentData

- 계열 `weaponClass` + `weightClass`, 단계 `stage` 1~4
- 명칭 `GetDisplayName()`: ???의 기억 → 불완전한 ~ → ~ → 완전한 ~의 기억
- `uniqueEffects`: 고유효과. **메인/서브 모두** 상시 적용
- `combo[]` / `heavyAttack` / `specialSkill` / `swapAttack` — 전부 `AttackStep`

### AttackStep (공격 한 동작)

- 타이밍: `startup`(선딜) / `recovery`(후딜) / `cancelable` / `hyperArmor`
- 배율: `damageMult` / `weightMult` / `rangeMult`
- 히트박스: `hitbox` + `offset`, 비용 `staminaCost`, `knockback`

### 장착 규칙

- 파편은 무기군 무관 장착 가능. 주먹 무기군만 같은 계열 강제(현재 경고만)
- 특정 무기↔파편 강제(7대검), 시너지 조합: 미구현

## 4. 입력/캔슬 규칙

- **기본공격**: 짧게 눌렀다 뗌 / **강공격**: 0.25s(`heavyHoldThreshold`) 이상 홀드 후 뗌
- **입력 버퍼**: 공격 종료 0.16s(`attackBufferWindow`) 전부터 누른 입력만 접수, 기본공격만 버퍼
- **강공격 선충전 금지**: 공격 중엔 홀드 타이머 정지
- **콤보**: 반복 순환, 후딜 후 `comboResetTime` 내 입력 없으면 1타로
- **캔슬**: `cancelable = true`인 스텝의 **후딜레이 중에만** 스왑/특수/회피/패링이 끼어들 수 있음. false면 스왑 교체도 불가. 선딜~히트는 항상 캔슬 불가
- **히트스턴**: 넉백 있는 공격에 맞으면 시전 중 공격 강제 캔슬 (cancelable 무시, 히트 전이면 데미지도 안 나감, 버퍼/홀드도 초기화)
- **하이퍼아머**: 스텝의 `hyperArmor` 체크 또는 `KnockbackReceiver.HyperArmorState` → 데미지만 받고 히트스턴/넉백/캔슬 무시

### 스왑 (Q) — FragmentLoadout

- 서브 있음: 메인↔서브 교체 → 새 메인의 스왑 스킬 발동
- 메인만 있음: 교체 없이 자기 스왑 스킬 발동
- 쿨타임 8s. `ResetSwapCooldown()` = 파훼 시스템 연동용

## 5. 데미지 파이프라인

```
최종 데미지 = 무기.damage × step.damageMult   ← baseDamage (버프 전)
            × 공격자 DamageDealt 배수          ← PlayerAttack/DummyAttacker
            × 대상 DamageTaken 배수            ← Health
```

피격 로그 형식: `피격! 21 = 기본 15 x 버프 1.4 x 디버프 1, 남은 HP 79`

### StatusEffects — value는 배수 입력

- **1 = 변화 없음, 1.5 = 1.5배, 0.7 = 0.7배** (내부에서 value−1로 변환해 합연산)
- 합연산: 1.5배 + 1.2배 = 1 + 0.5 + 0.2 = 1.7배
- 같은 id는 갱신(중복 없음). infinite 체크 시 지속시간 무시

```csharp
statusEffects.Add(new StatusEffect("buff_id", EffectStat.DamageDealt, 1.5f, 5f)); // 5초간 1.5배
```

- **주의**: 스크립트 기본값을 바꿔도 이미 저장된 인스펙터/에셋 값은 안 바뀜

### DamageInfo

`damage`(버프 적용), `baseDamage`(로그용), `weightDamage`, `knockback`, `guardable`(false = 방어 불가 공격), `source`

## 6. 히트 판정

- 오브젝트 없이 타격 순간 `OverlapBoxAll` 즉석 검사
- `AttackPoint`(앞면, 로컬 X +0.3~0.5)가 **안쪽 끝**, 바라보는 방향으로만 뻗음 + 스텝별 `offset`
- 최종 가로 = `hitbox.x × 무기.range × rangeMult`
- 디버그: `showHitbox` → 타격 순간 반투명 빨간 박스 0.15s 표시
- **벽 반동**: 히트박스가 `wallLayer`에 닿으면 반대로 `wallRecoil`(4) 밀림, Y 속도 유지

## 7. 피격 / 넉백

### Health

- 무적: `invulnDuration`(피격 후) + `SetInvulnerable(t)`(회피 등 외부 부여)
- `DamageInterceptor`(Func<DamageInfo,bool>): true 반환 시 완전 무효 (패링/방어가 사용)
- 이벤트: `OnChanged` / `OnDamaged` / `OnDeath`

### KnockbackReceiver (공용)

- 피격 시 공격자 반대로 밀림 + 위로 살짝(`upwardBoost`), 경직 `stunTime`(0.15s)
- **경직 중 감속(`deceleration`) → 경직 끝나면 가로 속도 강제 0** (끝없이 안 밀림)
- 경직 중 PlayerMovement 조작 무시, 히트스턴 캔슬/하이퍼아머 판단 담당
- `Apply(velocity, stun)`: 외부 호출용 (벽 반동, 패링 경직)
- 플레이어-적 물리 충돌은 Layer Collision Matrix에서 Player×Enemy 해제

## 8. 회피 / 패링 / 방어

### PlayerDodge (Shift)

- 지상 = 구르기(속도 12, 0.35s) / 공중 = 대시(속도 18, 0.15s, 중력 정지, **착지까지 1회**)
- 전체 무적 + 조작 잠금, 스태미나 3, 방향 = 이동 입력 우선
- 캔슬 규칙 적용 (cancelable 후딜에서만 공격 캔슬 가능)

### PlayerParry (우클릭)

- **짧게 = 패링**: 판정 0.15s(`parryWindow`), **방향 무관 타이밍만**. 헛치면 0.3s 후딜
    - 성공: 데미지/넉백 무효 + 스태미나 환급 + 공격자 경직 0.6s/밀침
    - **특수 패링**: `weightDamage > blockLimit`인 공격을 패링 → 마나/혈액 회복 (TODO)
- **홀드 = 방어**: 판정 창 끝나도 누르고 있으면 방어 전환, 떼면 해제
    - **방어 중 스태미나 회복 정지** (`Stamina.BlockRegen`)
    - 성공 조건: `guardable` + 무게 ≤ `blockLimit`(10) + 스태미나 ≥ 무게
    - 성공: 무게만큼 스태미나 소모, 데미지 0
- **가드 브레이크** (방어 실패 = 방어 불가 공격 / 한계 초과 / 스태미나 부족):
    - 무게만큼 스태미나 깎임, **최저 `staminaFloor`(3) 보장**
    - **뚫은 그 공격에만** 받는 데미지 `breakDebuff`(1.4배) 적용 — 인터셉터에서 걸고 OnDamaged에서 즉시 제거
    - 방어 자세 풀림
