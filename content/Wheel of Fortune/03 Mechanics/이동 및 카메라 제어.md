## 1. 플레이어 이동 — `PlayerMovement.cs`

### 구성 요건

- Player 오브젝트: `Rigidbody2D` + `CapsuleCollider2D` + `PlayerInput` + `PlayerMovement`
- `PlayerInput`: Actions = 기본 `InputSystem_Actions`, Behavior = **Send Messages**
- 자식 오브젝트 `GroundCheck`: 발밑에 배치, 스크립트에 할당
- 레이어: 바닥은 **Ground** 레이어, 스크립트의 Ground Layer에 지정

### Rigidbody 2D 설정 (중요)

|항목|값|이유|
|---|---|---|
|Gravity Scale|4|실크송식 묵직하고 빠른 낙하감|
|Collision Detection|Continuous|고속 낙하 시 바닥 뚫림 방지|
|Interpolate|Interpolate|물리 프레임 사이 보간, 시각적 떨림/파고듦 제거|
|Freeze Rotation Z|✔ (코드에서 자동)|캐릭터 회전 방지|

### 콜라이더 관련

- **Capsule Collider 2D 사용** — Box는 모서리가 바닥 이음새에 걸려 이동이 멈추는 문제 발생
- Friction 0 인 Physics Material 2D 적용 — 벽 달라붙음 방지
- 콜라이더 Offset X는 0 유지 — 방향 전환이 스케일 뒤집기 방식이라 오프셋이 있으면 뒤집을 때 콜라이더가 순간이동함

### 이동 로직

- 좌우 이동: 가속 없이 `linearVelocity.x = moveInput * moveSpeed` 즉시 적용 (실크송식 즉각 반응)
- 방향 전환: `localScale.x` 부호 뒤집기. 시작 시 원본 스케일(`baseScale`)을 저장해 크기 유지
    - 자식(AttackPoint 등)도 같이 뒤집히므로 히트박스 방향 자동 처리

### 점프 로직 (실크송 조작감의 핵심)

1. **점프 버퍼** (`jumpBufferTime` 0.1s): 점프 입력을 즉시 실행하지 않고 버퍼에 기록. 착지 직전에 눌러도 착지하자마자 점프됨
2. **코요테 타임** (`coyoteTime` 0.06s): 발판을 벗어나도 잠깐은 점프 허용. 버퍼와 코요테가 둘 다 유효할 때 점프 실행
3. **점프 컷 (가변 점프 높이)**: 상승 중 버튼을 떼면 상승 속도에 `jumpCutMultiplier`(0.1)를 곱해 **즉시** 깎음 (한 번만 적용, `jumpCutApplied` 플래그)
    - 중력 보강 방식(서서히 감속)은 최소 점프 높이가 커서 폐기함
    - 버튼 상태는 릴리즈 이벤트가 아니라 `jumpAction.IsPressed()` **폴링**으로 확인 (이벤트는 씹히는 경우 있음)
4. **낙하 가속** (`fallMultiplier` 1.7): 하강 시 추가 중력 — 올라갈 땐 가볍고 내려올 땐 빠르게
5. **최대 낙하 속도** (`maxFallSpeed` 15): 프레임당 이동 거리 제한 (터널링 방지 겸)

### 튜닝 가이드

- 점프가 너무 높음 → `jumpForce` ↓
- 톡 눌렀을 때 점프가 너무 큼 → `jumpCutMultiplier` ↓ (0.1 이하)
- 착지가 굼뜸 → `fallMultiplier` ↑
- 둥둥 뜨는 느낌 → Rigidbody Gravity Scale ↑

## 2. 카메라 — `CameraFollow.cs`

### 구성 요건

- Main Camera (Perspective)에 부착
- `Target` = Player, `Player Input` = Player의 PlayerInput (룩 기능에 필요)

### 화면 크기 계산 (Perspective 대응)

카메라가 원근이라 "화면 크기"는 플레이어 Z 깊이에서의 시야 범위로 매 프레임 계산:

```
halfH = |target.z - cam.z| * tan(FOV/2)
halfW = halfH * aspect
```

플레이어와 카메라의 Z 거리가 바뀌면 데드존도 자동으로 맞춰짐.

### 기본 구도 (rest framing)

- 좌우: 캐릭터가 화면 **중앙**
- 상하: 캐릭터 아래로 바닥이 `floorVisibleHeight`(**2**) 만큼 보이는 높이
    - `restOffset = -(halfH - floorVisibleHeight)` — 카메라 중심 기준 캐릭터의 기본 세로 오프셋
    - 이 값이 클수록 캐릭터가 화면 위쪽에 위치 → 룩 업 가동 범위 증가 (아래 참고)

### 팔로우 로직 (축별 독립, 트리거 방식)

상태는 축마다 3가지:

1. **정지**: 캐릭터가 데드존 안 → 카메라 안 움직임
    - 가로 데드존: 화면 폭의 1/3 (`horizontalDeadZone`)
    - 세로 데드존: 기본 위치(restOffset)부터 위로 화면 높이의 1/2 (`verticalDeadZone`) — 아래로 치우친 비대칭 존
2. **복귀 트리거**: 데드존을 **벗어나는 순간** `recenterX/Y = true` → 기본 구도를 향해 이동 시작
3. **복귀 이동**: 지수 접근으로 기본 구도(움직이는 목표)를 추적, 도착(오차 0.02)하면 다시 정지

지수 접근 (프레임레이트 무관, 끝없이 수렴):

```csharp
Lerp(current, goal, 1 - Exp(-speed * dt))
```

- `horizontalSpeed` 5 / `verticalSpeed` 3 — 세로를 더 느리게

### 하드 클램프 (안전장치)

따라가는 속도가 아무리 느려도 캐릭터가 화면 밖으로 나가지 않게:

- 기준 위치: 캐릭터가 화면 가장자리에서 `edgeMargin`(1) 안쪽 유지
- 룩 적용 후: `lookEdgeMargin`(0.3) 안쪽까지 허용

### 룩 업/다운

- 조건: **좌우 입력 없이** Move의 위/아래(W/S, ↑/↓)만 `lookHoldTime`(1s) 유지 + 캐릭터 정지 상태(속도 기준, 약간 여유 있게 판정)
- 동작: 카메라가 `lookDistance`(4) 만큼 위/아래로 지수 접근 이동, 키를 떼면 복귀
- **주의 (버그 이력)**: 룩 오프셋은 클램프에 막힌 뒤 **실제 적용된 값만** 저장해야 함
    - `lookOffset = newY - newBaseY`
    - 이걸 안 하면 클램프에 막힌 가상의 오프셋이 기준 위치를 오염시켜서, 룩이 끝났을 때 카메라가 엉뚱한 위치(캐릭터 정중앙)로 정착함
- 룩 업 가동 범위는 `floorVisibleHeight - lookEdgeMargin` 근처로 제한됨 (기본 구도에서 캐릭터가 이미 화면 아래쪽에 있기 때문). 룩 업을 더 크게 하려면 `floorVisibleHeight` ↑

### 기타

- 카메라 이동은 `LateUpdate`에서 처리 (플레이어 물리 이동이 끝난 후)
- 씬 뷰에서 카메라 선택 시 기즈모 표시: 노랑 = 가로 데드존, 초록 = 세로 기준선/상한선
- 인스펙터에 이미 붙은 컴포넌트는 스크립트 기본값이 아니라 **인스펙터 값이 우선** — 값 바꿀 땐 인스펙터에서

## 3. 트러블슈팅 이력

| 증상                   | 원인                    | 해결                                          |
| -------------------- | --------------------- | ------------------------------------------- |
| 이동 시 캐릭터 크기가 1×1로 고정 | 뒤집기 코드가 스케일 하드코딩      | 원본 스케일 저장 후 X 부호만 변경                        |
| 점프 높이가 항상 동일         | 릴리즈 이벤트 미수신           | `IsPressed()` 폴링 방식으로 전환                    |
| 짧게 눌러도 최소 점프가 큼      | 중력 보강 방식의 한계          | 릴리즈 순간 속도 하드 컷                              |
| 착지 시 바닥 뚫고 들어감       | Discrete 충돌 + 고속 낙하   | Collision Detection Continuous, Interpolate |
| 이동 중 가끔 멈춤 (점프하면 풀림) | Box 콜라이더 모서리 걸림       | Capsule Collider 2D로 교체                     |
| 룩 업 무반응 + 종료 후 중앙 정착 | 클램프에 막힌 오프셋이 기준 위치 오염 | 실제 적용된 오프셋만 저장                              |
